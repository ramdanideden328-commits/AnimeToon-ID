# AnimeToon-ID

Selamat datang di repository resmi **AnimeToon-ID**! Aplikasi ini dibuat untuk memudahkan kamu menonton dan menikmati berbagai serial anime kesayangan dengan subtitle Bahasa Indonesia.

## Fitur Utama
- Nonton anime subtitle Indonesia.
- Tampilan antarmuka yang simpel dan mudah digunakan.
- Update episode terbaru.

## Cara Install / Menggunakan
1. Masuk ke menu **Releases** (Rilis) di bagian kanan halaman ini.
2. Unduh file aplikasi terbaru (versi `v1.0.0`).
3. Pasang dan jalankan aplikasinya di perangkat kamu.
